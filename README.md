# Life Unit Calculator: test page

A test build of the Life Unit Calculator, published so it can be shared and tried. It quotes any amount in dollars, euros, pounds, Singapore or Australian dollars, Bitcoin or satoshis as Life Units and as time of an abundant day, from a published fix, and shows the work behind the figure so a reader can verify it in the page.

The data is placeholder. The page says so in its banner. Nothing on it was witnessed from a real source and no number on it is a quote. The method is the Life Unit Standard methodology v0.9 (the computation model); the source of record for the page and the formula engine is the private uni-life-unit-standard repository, branch computation-model, folder _DRAFTS/02 - For AI/Calculator.

Two files, no build step, no framework. The one outside call is to a public price API and runs only when the reader presses its button.

Life is the way it can be measured in units. Life Units.
